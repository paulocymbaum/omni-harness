Status: ready

## Objetivo

Encerrar formalmente a entrega do harness de ciclo criando o diretório `specs/` com um arquivo `specs/<ID>.md` para cada uma das 15 tarefas do backlog (RB-001 a RB-015). Esses arquivos são o registro de investigação que prova que cada tarefa foi especificada antes de ser implementada. A existência dos 15 arquivos é verificada automaticamente pelo gate EG-REG via `backlog.mjs validate --require-specs`. O gate EG-PILOTO (execução real ponta a ponta) é manual e é pulado automaticamente pelo runner.

Cada `specs/<ID>.md` deve conter pelo menos a linha `Status: ready` e o título da tarefa correspondente no cabeçalho (`# <ID> — <título>`). O formato completo recomendado inclui as seções: Objetivo, Contrato de implementação, Gates, Riscos e dependências, Evidência de investigação.

**Verificação:**
O gate EG-REG executa:
```
node quality/delivery/backlog.mjs validate docs/entregas/2026-10-01-harness-entrega-em-ciclo --require-specs
```
A função `checkSpecs` (em `quality/delivery/backlog.mjs`, linha 102) itera todas as tarefas do backlog e verifica `fs.existsSync(path.join(dir, 'specs', '<ID>.md'))`. Basta o arquivo existir para o gate passar.

## Gates

- **EG-REG** (command): `node quality/delivery/backlog.mjs validate docs/entregas/2026-10-01-harness-entrega-em-ciclo --require-specs` — passa quando todos os 15 arquivos `specs/<ID>.md` existirem.
- **EG-PILOTO** (manual): execução da entrega piloto ponta a ponta — pulado automaticamente pelo runner (`eval.mjs`) quando o tipo é `manual`.

## Riscos e dependências

- **Dependências**: RB-001 a RB-013 devem estar `done` (conforme `depends_on` do backlog). Todas estão `done` na data desta spec.
- **RB-014 não está em `depends_on`**: a tarefa de espelho Jira (RB-014) não é dependência formal de RB-015 no backlog. A spec cobre apenas o que o gate EG-REG verifica.
- **Risco de path**: `checkSpecs` usa `path.join(dir, 'specs', '<ID>.md')` — o diretório de base deve ser o mesmo passado ao comando `validate`. Sempre usar o caminho absoluto `docs/entregas/2026-10-01-harness-entrega-em-ciclo`.
- **Specs retroativas**: as tarefas RB-001 a RB-014 já estão `done`. As specs criadas na fase C são documentação retroativa — não alteram o código já entregue.

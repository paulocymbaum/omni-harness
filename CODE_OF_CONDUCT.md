# Código de Conduta

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) como código de conduta de toda a comunidade — issues, PRs, discussões e espaços relacionados.

## Compromisso

Buscamos um ambiente aberto, acolhedor e respeitoso: assédio, ataques pessoais, trollagem, publicação de dados privados de terceiros e qualquer forma de discriminação não são tolerados.

## Aplicação

Violações podem ser reportadas abrindo uma issue marcada como `conduct` **sem detalhes sensíveis** ou via [GitHub private vulnerability reporting](https://github.com/paulocymbaum/omni-harness/security/advisories) para casos que exijam sigilo. A manutenção se reserva o direito de remover, editar ou rejeitar contribuições que violem este código.

Atribuição: [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
